> **Where Modern Psychiatric Science Meets Eternal Temple Peace**

## 🚀 How to Run

### Option 1: Run the Production Server (Lightning Fast)
```bash
node server.js
```
Open **[http://localhost:4300](http://localhost:4300)** in your browser.

### Option 2: Run with Angular CLI (Development with Hot Reload)
```bash
npm start
```
Starts `ng serve --port 4300`.

### Running the Sister Websites Simultaneously:
- **Sukoonsay (Psychiatrist)**:
  ```bash
  cd d:\Sakoonsay
  node server.js
  ```
  Runs at `http://localhost:3000`
- **Sakoon-Temple (Spiritual Sanctum)**:
  ```bash
  cd d:\Sakoon-Temple
  npm start
  ```
  Runs at `http://localhost:4200`
